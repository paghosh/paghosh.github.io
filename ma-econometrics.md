## About the program

The Online MA in Econometrics admitted its first cohort in Spring 2025. It is a 30 credit hour, fully online degree that can be completed in 15 to 21 months. The curriculum covers applied econometrics, machine learning methods, and Python programming for data analytics.

Admission requirements, tuition, and the intended audience are described on the official program page.

## Courses I teach in the program

- **ECON 5213, Advanced Econometrics.** Regression methods and applications (Spring 2025 and 2026).
- **ECON 5083, Applied Labor Economics.** Labor economics for the program (Summer 2026).
